# 卡面图设计规范（Phase 8b · AI 生图）

本文件是 72 张英灵卡面的**设计基线**。数值基线见 [`plan.md`](plan.md)（§8 角色、§2 合规红线）。
提示词由 `tools/artgen/prompt.ts` 按本规范生成，改画风只改该文件里的 `STYLE_BLOCK`，
不改任何英灵数据。

---

## 1. 一句话定位

> **「被圣杯召来、仍在自己年代里」**——每位英灵是历史人物本人，不是奇幻世界的翻版；
> 画面用统一画风串成一套世界观，靠服饰、兵器、器物与气质区分个体。

---

## 2. 统一画风（全组 72 张共用一段常量）

| 方案键 | 描述 | 适用判断 |
|---|---|---|
| `cg` | 半写实厚涂 CG 游戏原画（AAA 手游立绘质感） | 跨文化统一性最好，贴合暗金 UI；默认 |
| `ink` | 国风水墨工笔人物画，宣纸质感与淡彩设色 | 东亚史诗感强，西方角色需另做变体 |
| `cel` | 二次元赛璐璐动画角色原画，线稿 + 平涂色块 | 色彩明快、辨识度高，整体偏轻快 |

**换画风 = 只改 `STYLE_BLOCK` 一处**，其余三层（形象 / 姿态 / 背景配色）保持不变，
这样 72 张的构图与个体特征可复用，只需重跑生图。

## 3. 三层可辨性结构

每位英灵的卡面 = **风格锁定** + **个体特征** + **系统标签**，缺一不可。

### 3.1 个体特征（每人一组，来自 `HERO_DETAIL`）

只写**史实可考**的服饰、兵器、器物、随身物：

- 项羽 → 楚式劲装重甲、赤色战袍、厚重长戟
- 诸葛亮 → 素白纶巾、青灰鹤氅、白羽扇
- 祖冲之 → 圆规算筹、浑天仪与水碓模型
- 南丁格尔 → 维多利亚深色长裙、提铜柄油灯
- 达·芬奇 → 赭红长袍、手绘扑翼机设计图

未单独登记的英灵走「地域 × 时代」通用描述兜底（`CULTURE_LOOK`）。

### 3.2 定位标签（五维定位 → 姿态与道具）

| 定位 | 体态与姿态 | 典型道具 |
|---|---|---|
| 猛将 | 高大结实、披风重甲、兵器斜指地面 | 长戟、长矛、大刀 |
| 统帅 | 挺拔沉稳、按剑或执节杖 | 佩剑、权杖、旗 |
| 谋士 | 清瘦长袍广袖、一手作推演之势 | 竹简、卷轴、星盘 |
| 医者 | 清瘦温润、眉眼柔和 | 药箱、油灯、药草 |
| 器者 | 清瘦专注、双手托举精密器物 | 尺规、镜筒、齿轮、罗盘 |

### 3.3 五行标签（五行 → 背景意象与主色）

| 五行 | 背景 | 主色 |
|---|---|---|
| 金 | 金属碎片、断裂刀刃、锐利光束 | 冷白 + 淡金 |
| 木 | 虬曲枝干、藤蔓、竹叶 | 青翠 + 嫩绿 |
| 土 | 层叠岩层、夯土城墙剪影、沙尘 | 赭黄 + 暖褐 |
| 水 | 流动水纹、涟漪、雾气、光柱 | 青蓝 + 月白 |
| 火 | 摇曳火焰、飞散余烬、地面火光 | 赤红 + 橙金 |

**稀有度只影响光效强度与背景复杂度**，不改配色方向：SSR 金色轮廓光 + 结界纹样，
SR 淡光晕，R/N 背景收敛。

## 4. 版式

| 版式键 | 比例 | 取景 | 用途 |
|---|---|---|---|
| `card` | 3:4 | 半身，自大腿以上 | 完整卡面：抽卡结果、英灵详情、图鉴 |
| `avatar` | 1:1 | 胸像，自腰以上 | 直接替换现有 72px 头像位 |

方形头像位已在 `.portrait` 上用 `object-fit: cover`，
竖版卡面放进去会自动裁到头肩区域，两种版式都不需要改 UI 布局。

**展示口径**（Phase 8b 接入时落实）：

| 界面 | 展示方式 |
|---|---|
| 抽卡结果弹窗 | 新获得英灵以 **3:4 完整卡面**（84×112）成排展示，铭牌文字由 UI 叠加 |
| 英灵详情 | 顶部为 **3:4 完整卡面**（132×176），不裁切 |
| 图鉴 / 圣殿 / 阵位 / 铸造 / 推征 | 方形缩略（72×72 / 40×40），`object-fit: cover` 裁到头肩 |

**未解锁态**：图鉴里未解锁的卡面用 `grayscale(0.9) brightness(0.62) contrast(0.95)` 压暗。
占位 SVG 时代用的 `brightness(0.35)` 会把 AI 卡面压成纯黑方块——完整画面不像高对比剪影，
那样看起来像图片加载失败，而不是「未解锁」。

## 5. 合规约束（每条提示词都带）

1. **原创画风**：不指向任何现成游戏 / 影视 / 博物馆图像（含博物馆摄影作品，摄影权另计）。
2. **中立面孔**：可信成年人面貌，神情专注沉着，不做夸张表情，不做美丑与功过评价。
3. **无文字**：画面不出现任何文字、汉字、字母、数字、logo、水印——**铭牌文字一律由 UI 叠加**，
   避免模型写出错字。
4. **无第二人物 / 无宠物坐骑 / 无现代物品 / 无真实国旗徽章宗教标识 / 无血腥**。
5. **解剖正确**：手指结构正常完整，无多指畸形。

> ⚠ 「必出」「100%」等绝对化用语属禁用词表，**卡面文案与图内文字都不得出现**
> （见 `src/content/compliance/forbidden-words.md`）。

## 6. 生产流水线

```bash
# 1) 生成批次请求（每批 10 张）
npx tsx tools/artgen/build-batch.ts cg card

# 2) 逐批调用 H3 Image（每次最多 10 条请求）
npx tsx tools/artgen/run-batches.ts      # 内含限流节流与退避重试，可中断续跑

# 3) 回执落盘 → public/portraits/<heroId>.jpg，并回写资源登记表
npx tsx tools/artgen/save-results.ts tools/artgen/out/batch-01-receipt.json ...

# 4) 技术校验（尺寸 / 比例 / 完整性 / 重复图 / 覆盖率）
npx tsx tools/artgen/verify.ts

# 5) 客观复检（只查文字与手部）+ 定向重生成
npx tsx tools/artgen/focus-check.ts 9 --force   # --force 覆盖已有结果
npx tsx tools/artgen/focus-report.ts             # 汇总，人工裁定覆盖模型判定
npx tsx tools/artgen/split-batch.ts              # 拆成 ≤10 张一批
npx tsx tools/artgen/run-batches.ts              # 重跑问题卡面
npx tsx tools/artgen/save-results.ts tools/artgen/out/batch-11-receipt.json

# 6) 争议项裁定（可选）：只问「能否读出具体字词」
npx tsx tools/artgen/tiebreak.ts shangyang luban
```

- 产物路径 `public/portraits/<heroId>.jpg`，与占位 SVG 同名不同扩展名。
- 可用性登记在 `src/core/config/art.ts`（core 纯逻辑层不访问文件系统，构建期登记）。
  未产出卡面的英灵自动回落到 SVG 占位头像，**不会 404**。
- 生图参数：`aspect_ratio` 由版式决定，`area=1K`（约 1024²，移动端 H5 足够），
  `output_format=jpeg`（同源 SVG 占位相比体积可控）。
- **服务端限流约 20 张/分钟**，超过会返回 429（`request limit reached`）。
  `run-batches.ts` 内置 45s 批次节流与 70s 退避重试。

## 6.5 校验的三层做法（重要经验）

第一轮用「八项清单」让视觉模型逐张评审，结果 **63/72 被判需修改**——但抽查发现
大部分是**史实洁癖**：把 AAA 手游立绘的艺术夸张当成缺陷
（「张飞的兵器应更像丈八蛇矛」「战国人物必须戴冠帽」「出现盘扣是清代形制」）。
用户选定的就是游戏卡面风格，按博物馆标准重画会把画面退化成陈列柜。

因此改为**三层校验**：

| 层 | 工具 | 判什么 | 结论 |
|---|---|---|---|
| 第一层 | `visual-check.ts` | 八项清单全文 | 只作**观察项**记录（服饰风格化 8 张、手部略糊 6 张），不触发重生成 |
| 第二层 | `focus-check.ts` | **两个客观二元问题**：画面有无文字/符文/水印；手指数对不对 | **主判据**，触发重生成 |
| 第三层 | `tiebreak.ts` + 人工裁定 | 有没有**能读出具体字词**的文字 | 裁掉误报，只留下真问题 |

**经验 1**：让视觉模型评「风格/史实」会产生大量噪声；让它回答**可观测的客观事实**
（有没有字、手指几根），信号干净得多。以后做美术质检都按这个套路。

**经验 2**：第二层问「有没有类似符文的笔画」仍然偏宽——饕餮纹、团花纹、法阵、兵法阵图
都会被判成「有文字」。第三层换问「能否读出具体字词」，并把纯装饰纹样、几何图案、
法阵、星图、刻度明确列为「不算文字」，噪声立刻降下来。

**经验 3**：模型判「有」不等于真是问题，最终以**人眼看原图**为准。
人工判定落盘在 `tools/artgen/manual-adjudication.json`（含理由，**进版本库**），
`focus-report.ts` 读取后以人工裁定覆盖模型判定，保证每次重跑结论一致、可回溯。

三轮实测（72 张）：

| 轮次 | 模型判定 | 人工裁掉 | 实际重生成 |
|---|---|---|---|
| 第二层首次 | 文字/符文 19、手部 6 | 3 张风格元素（法阵/星图） | 20 张 |
| 第二层重跑 | 文字/符文 7、手部 1 | 5 张装饰纹样误报 | 2 张（商鞅铜尺刻字、鲁班三角尺字母刻痕） |
| 第三层复检 | — | — | 0 张（商鞅改素面铜尺、鲁班改木鹊陶壶，均已干净） |

最终结论：**72/72 全部通过**——无文字、无手部畸形、无第二人物、无现代物品。

## 6.6 工具链约定（踩过的坑）

| 约定 | 原因 |
|---|---|
| 分组与 id 的对应由 `focus-check.ts` 写 `focus-groups.json` 唯一定义，`focus-report.ts` 只读不重算 | 两边各算一遍顺序，改动后立刻对不上号，结论张冠李戴 |
| 回执遍历取「**后写入覆盖先写入**」 | 重生成批次号更大；用「首次出现优先」会拿旧图复检，重生成成果无法验证 |
| `focus-check.ts --force` 覆盖已有分组结果 | 重生成后必须重跑；默认跳过是给分批续跑用的 |
| 人工裁定落盘 `tools/artgen/manual-adjudication.json`，含理由 | 结论要可回溯、可复核，而不是每次重新目测（该文件进版本库，不放 `out/`） |
| `tools/artgen/out/` 在禁用词扫描中排除 | 那是模型复述文本与批次回执，不是对外文案 |
| `save-results.ts` 只解析 `AI_CARD_IDS` 数组块 | 手改成单行 `['x']` 会被漏掉 |
| `tools/artgen/out/` 已加入 `.gitignore` | 中间产物不进版本库 |
| 界面截图一律走 `tools/capture/screenshot.ts`，目标 origin 只允许 `127.0.0.1:<隔离端口>` | **localStorage 按 origin 隔离**：脚本访问玩家正在游玩的 `localhost:5173`，等于共用玩家存档并真的抽走资源（历史教训：一次性截图脚本点了十连，玩家 3000 结晶被抽走）。工具内置 origin 守卫 + 全新隔离 context，命中即拒绝执行 |

## 7. 人工校验清单（每张必查）

| 项 | 检查点 |
|---|---|
| 服饰年代 | 是否属于该英灵所处时代，是否混入了后世形制 |
| 兵器 | 是否该时代该地域会用的形制，是否出现跨时代兵器 |
| 年龄 | 是否与生平阶段相符（青年 / 中年 / 晚年） |
| 发式 | 是否符合该时代该地域的发式与冠帽 |
| 姿态气质 | 是否符合「猛将 / 统帅 / 谋士 / 医者 / 器者」定位 |
| 五行 | 背景意象与主色是否对得上该英灵五行 |
| 合规 | 无文字、无水印、无真实国旗徽章、无第二人物、无血腥 |
| 解剖 | 手指、肢体、面部对称无畸变 |

> 史实错误（服饰 / 兵器 / 年龄 / 发色）由**人工校验 + 替换**兜底：
> 该 id 重新生成即可，登记表按 id 覆盖，不影响其他英灵。
