# 资源、背包与材料副本设计

2026-11-19 · 目标版本设计稿。下文的「定案」记录本轮确定的玩法，「建议」是交给原型和数值模拟验证的起点。当前版本的实现记录见 [项目设计基线](plan.md)，落地顺序见 [实现计划](resource-backpack-implementation.md)。

## 一、玩家每次上线做什么

推主线赚银两、经验书和遗物，首次通关再领圣杯结晶。用结晶抽英灵，新卡入队，同名重复卡变成该英灵的碎片。卡关时有三种选择：用库存经验书练人，去五行副本升关键技能，或去强化石副本提升主力遗物。换完阵容、花完材料，可以回来重试同一关。

**定案**　钱包只有银两和圣杯结晶。背包装遗物、五行技能材料、三档强化石、两种通用经验书和同名碎片。材料副本只有技能、强化两类。经验书全职业通用，由主线产出。

## 二、每种资源从哪来、用在哪

下表的主线包含在线和离线推征。副本名称和材料名称暂作工作名；附加投放（开局、签到、任务等）的建议口径见下一节。

| 钱包或背包条目 | 主要来源 | 消耗或用途 |
|---|---|---|
| 银两 | 主线首通与复刷；遗物分解 | 支付技能升级和遗物强化费用。建议境界突破也花银两 |
| 圣杯结晶 | 主线各关首次胜利；开局、签到和已有兑换码建议继续投放 | 召唤英灵。沿用每抽 300、十连 3,000；由同一付费规则报价、验资、扣款 |
| 小经验书 | 主线胜利，前期以小书为主 | 喂给任意英灵，增加少量个人经验，适合补一级 |
| 大经验书 | 主线胜利，中后期提高大书占比 | 喂给任意英灵，一次提供更多个人经验，适合培养新卡 |
| 金系技能材料 | 技能副本·金 | 金属性英灵的技能升级，另付银两 |
| 木系技能材料 | 技能副本·木 | 木属性英灵的技能升级，另付银两 |
| 水系技能材料 | 技能副本·水 | 水属性英灵的技能升级，另付银两 |
| 火系技能材料 | 技能副本·火 | 火属性英灵的技能升级，另付银两 |
| 土系技能材料 | 技能副本·土 | 土属性英灵的技能升级，另付银两 |
| 初阶强化石 | 强化副本·初阶 | 遗物目标等级 **1～60**，另付银两。遗物取得时为 1 级，第一次付费是 1 → 2 |
| 中阶强化石 | 强化副本·中阶 | 遗物目标等级 **61～130**，另付银两。60 → 61 用中阶石 |
| 高阶强化石 | 强化副本·高阶 | 遗物目标等级 **131～200**，另付银两。130 → 131 用高阶石，200 级满级 |
| 某英灵的同名卡碎片 | 抽到该英灵的重复卡，N、R、SR、SSR 均适用 | 只给该英灵升星。升星只扣同名碎片。十连内同一卡首次获得本体，后续重复逐张转化 |
| 遗物 | 主线普通关和章末 BOSS 的掉落；关卡详情预览可掉套装 | 装备给英灵获得属性和套装效果，可强化、锁定或分解。每件独立保存等级、词条和装备关系 |

**三项消耗边界**

- **喂经验**按书的数量扣库存，经验计入所选英灵。保留现有境界门槛及门槛上的经验进度；突破后立即兑现。满级停止用书，批量使用先预览实际消耗与结果。
- **升星与突破**分开。所有稀有度都能靠同名碎片升星。建议 Lv60、120、180 的境界突破改扣银两，维持低星英灵通往满级的路线；重启保留星级、碎片和背包材料。满星后的同名碎片继续按同一规则入包，本版不另设兑换货币。
- **强化与分解**按目标等级逐级报价。一次从 59 升到 62，消耗 1 个初阶段升级步骤和 2 个中阶段升级步骤对应的石量。61 级起沿用淬炼成长定位。建议分解只返银两，获得遗物到满仓处理均不携带副本材料；返还金额要通过投入与返还核算。

## 三、主线和副本各给什么

| 场景 | 玩家得到什么 | 节奏与限制 |
|---|---|---|
| 主线普通关、章末 BOSS | 银两、经验书、遗物；账号首次打赢该关另给结晶 | 每关详情分列「重复挑战」和「首次通关」。旧关仍可积累养成资源；观战预览不发奖 |
| 技能副本 | 选定五行的技能材料 | 五行常驻开放。建议胜利保底获得目标材料，难度影响数量。首个可升级技能出现时能进入对应副本 |
| 强化副本 | 选定档位的强化石 | 三档定向选择。首件遗物到手即可刷初阶；主力装备到 60、130 级时已有下一档的可挑战入口 |
| 签到、开局、兑换码 | 建议保留各自的结晶供给，原券按每张 300 结晶折算 | 新号仍有 20 抽购买力。签到提供通关主线以后的稳定结晶收入。「仅首通」限定主线发放 |
| 日常、周目标、回流 | 建议用少量通用经验书承接辅助养成奖励 | 单列辅助投放预算；技能和强化材料的常规刷取入口仍是两个定向副本 |
| 竞技场、三队天梯 | 建议以各自的段位分、已有称号承接竞技成绩 | 竞技勋章和竞技材料停止新增，旧余额留记录。原竞技券奖励建议随竞技货币调整一并退场，单列对总抽数的影响 |

**建议的挂机体验**　首页在「主线 / 技能 / 强化」中选择一个去向。三个去向共用一份挂机时间；切换前结清旧目标的收益，之后的时间用于新目标。材料不足时，养成页直接打开匹配的副本，并显示差额、每胜产量和返回主线入口。主线沿用战败后回刷和重试；副本失败给出可刷的低难度选择。主线首通记录跨设备、跨重启，离线连续过关也逐关发奖。

**留给试算的数值**　可从每章 30 个普通关各给 10 结晶、BOSS 给 300 起算，即每章 600 结晶、十章共 20 抽；与开局和签到分账。首胜先给可装备的遗物，后续降低普通关遗物件数，提高章末目标套装的可预期性。每本经验、每场掉量、遗物频率、各星碎片数、升级银价和副本难度均需模拟后定表。检验重点是第一次升级能否靠主线自然完成，以及升完 60、130 级后获取下一档石头需要多久。

## 四、背包怎么用

| 分类 | 展示单位 | 筛选、排序和常用动作 |
|---|---|---|
| 遗物 | 每件一个实例 | 按套装、稀有度、已装备和锁定状态筛选；按等级或稀有度升降序。查看对比、装备、强化、锁定和分解 |
| 技能材料 | 五行各一叠 | 按五行筛选，按五行或数量排序；查看可使用的英灵和对应副本 |
| 强化材料 | 三档各一叠 | 按档位或数量排序；标出适用等级、可强化的遗物和来源 |
| 经验书 | 小书、大书各一叠 | 按单本经验或数量排序；选英灵、选数量，预览升级结果后使用 |
| 卡碎片 | 每位英灵各一叠 | 按英灵或数量排序，可筛出「可升星」；显示持有量、升星所需和直达入口 |

顶栏展示两种货币，主导航提供背包入口。建议遗物沿用现有仓库分页及容量保护，材料按道具种类堆叠，单独计数。由英灵或遗物详情进入时自动带入相关筛选；数量相同的条目按稳定的次序排列。玩家在结算面板看到的数量，与背包本次实际增加或溢出分解的数量一致。
